# Dataset

The preparation script downloads the **SpamAssassin Public Mail Corpus** from Apache's public corpus archive. It uses `20030228_easy_ham.tar.bz2` (ham) and `20030228_spam.tar.bz2` (spam). The corpus README describes approximately 2,500 easy ham and 500 spam messages in these groups. Counts in the prepared CSV are measured from files that actually parse and are written by the script; archives can contain malformed/duplicate records.

Run `python src/prepare_data.py` from the project root. Archives and extracted messages stay under `data/raw/`; the prepared `data/processed/emails.csv` is generated locally and is excluded from Git. If automatic download is unavailable, download those two `.tar.bz2` files from [Apache's corpus archive](https://spamassassin.apache.org/old/publiccorpus/) into `data/raw/`, then run `python src/prepare_data.py --local`.

Labels come from the archive's directory names, not message content: `easy_ham` = ham and `spam` = spam. This is an old, curated corpus, with a deliberate easy-ham subset and roughly 5:1 class imbalance. It does not represent today's mail, languages, phishing, or varied user inboxes. Exact normalized subject/body duplicates are removed before splitting. The preparation script also writes `near_duplicate_audit.csv`, screening pairs with character TF-IDF cosine similarity at least 0.95; these are reported but retained because similar campaign messages may be distinct observations. In the observed run, this heuristic found 1,440 candidate pairs, with 541 crossing the train/test split (9 cross-split pairs had different labels). This indicates potential template overlap; it could inflate scores and is an important limitation. The heuristic is not a complete near-duplicate detector.
